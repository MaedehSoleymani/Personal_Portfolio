# Mahy — Personal Portfolio

A responsive bilingual (English/Persian) personal portfolio built with vanilla HTML, CSS and JavaScript.

## Run locally
Open `index.html` in your browser, or run:

```bash
python3 -m http.server 8000
```

Then visit http://localhost:8000.

## Before publishing
- Replace `your.email@example.com` with your public contact email.
- Update LinkedIn URL.
- Add repository links for Afterword and BoxOCR Bot.
- Review skill levels, dates and experience wording.

## Publish with GitHub Pages
1. Create a repository named `YOUR-USERNAME.github.io`.
2. Upload `index.html`, `style.css`, `script.js`, and `README.md` to the repository root.
3. In repository Settings → Pages, select deployment from the `main` branch and `/ (root)`.
4. Your site will be available at `https://YOUR-USERNAME.github.io`.

No build step is required.
